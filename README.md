# Forensic Data Analytics for Anomaly Detection in Evolving Networks Using Wireshark

## Overview

This project focuses on analyzing network traffic and detecting anomalies using Wireshark. By capturing and examining packet-level data, the system helps identify suspicious activities, unusual traffic patterns, and potential security threats in evolving network environments.

## Objectives

* Capture and analyze network traffic using Wireshark.
* Detect abnormal network behavior and security incidents.
* Perform forensic analysis on captured packets.
* Generate insights from network traffic data.
* Improve network monitoring and threat detection capabilities.

## Technologies Used

* **Wireshark** – Network packet capture and analysis
* **Python** – Data processing and analytics
* **Pandas** – Data manipulation
* **NumPy** – Numerical computations
* **Matplotlib/Seaborn** – Data visualization

## Features

* Real-time and offline packet analysis.
* Detection of unusual network traffic patterns.
* Protocol-based traffic inspection.
* Visualization of network statistics.
* Forensic investigation support for cybersecurity incidents.

## Project Workflow

1. Capture network packets using Wireshark.
2. Export packet data for analysis.
3. Clean and preprocess network traffic data.
4. Apply anomaly detection techniques.
5. Visualize findings and generate reports.
6. Identify potential threats and suspicious activities.

## Dataset

The dataset consists of network packet captures (PCAP files) collected using Wireshark. These files contain information such as:

* Source and destination IP addresses
* Protocol types
* Packet sizes
* Timestamps
* Network flow details

## Results

The project successfully identifies anomalous network behavior by analyzing traffic patterns and highlighting deviations from normal activity. This helps in early detection of potential cyber threats and supports digital forensic investigations.
